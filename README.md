# Azure for Students · Manual completo

Manual web estático para principiantes, centrado en Azure for Students, control del crédito, conceptos fundamentales y configuración guiada de servicios. Incluye laboratorios completos con Windows Server 2022 e IIS, Ubuntu Server 24.04 LTS y NGINX, acceso remoto seguro, transferencia de sitios por SFTP con Cyberduck y un módulo complementario con ocho prácticas de Storage, Static Web Apps, SQL Database, Functions, Monitor, Key Vault, Backup y RBAC.

## Publicación en GitHub Pages

1. Suba todos los archivos de esta carpeta a la raíz del repositorio. Asegúrese de incluir `advanced.css`, `juego.html`, `game.css`, `game.js`, `practicas-servicios.html`, `practicas-servicios.css` y `practicas-servicios.js`.
2. En GitHub abra **Settings → Pages**.
3. En **Build and deployment**, seleccione **Deploy from a branch**.
4. Elija la rama principal, carpeta `/ (root)` y pulse **Save**.

No requiere instalación, compilación ni servidor. El progreso del manual, el juego y las prácticas complementarias se guarda localmente en el navegador del aprendiz.
